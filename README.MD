# QA Portfolio · Глеб Хряп

Начинающий тестировщик, студент 4 курса по специальности «Информационные системы и программирование».
Здесь — автотесты, которые я пишу, осваивая автоматизацию.

## Что внутри

| Папка | Содержание |
|---|---|
| `tests/` | UI-автотесты на Selenium + pytest |
| `conftest.py` | Фикстура браузера: запуск и гарантированное закрытие |

## Стек

Python 3.13 · pytest · Selenium 4

## Как запустить

```bash
git clone https://github.com/ТВОЙ_НИК/qa-portfolio.git
cd qa-portfolio
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pytest -v
```

## Что умею в тестировании

- Тест-кейсы и чек-листы: 39 кейсов на регистрацию, чек-лист на 57 проверок с 21 найденным дефектом
- Баг-репорты с локализацией до фронтенда или бэкенда через DevTools
- Тест-план и тест-дизайн по REST API на учебном проекте
- API: Postman, SQL для проверки данных
