## 1. Форма регистрации

**Позитив**

✅ Телефон +7 9XX XXX-XX-XX (личный номер скрыт) принимается
✅ Кнопка принятия соглашений при нажатии меняет состояние
✅ Нажатие на кнопку «Телефон» с введённым номером +7 9XX XXX-XX-XX (личный номер скрыт) и принятым соглашением продолжает регистрацию
🐞 Дата рождения 08.08.2026 (будущая дата) не принимается — *принимается*
✅ Пол «мужской» принимается
✅ Пол «женский» принимается
🐞 После регистрации в профиле отображается номер телефона пользователя — *не отображается*
✅ Выбор способа регистрации Telegram исправен
✅ Выбор способа регистрации Max исправен
✅ Нажатие на кнопку с соглашением открывает страницу с соглашением

**Границы**
✅ Ввод имени «ы» (1 символ) принимается
🐞 Имя «123» из одних цифр не принимается — *принимается*
🐞 Ввод спецсимволов в имени не принимается — *принимаются*
🐞 Ввод пустого имени не принимается — *принимается*
🐞 Длина имени ограничена верхним пределом — *предел отсутствует, принято 1685 символов*

**Негатив**
✅ Ввод несуществующего номера +711111111 выдаёт ошибку
✅ Ввод букв в поле телефона не допускается
✅ Ввод пустого поля номера телефона не допускается
✅ Ввод спецсимволов в поле телефона не допускается
✅ Пропуск цифры в номере 7111 11111 не допускается
✅ Вставка скопированного текста в поле телефона не допускается
🐞 Выбор даты рождения 12.12.1890 не допускается — *допускается*

**Интерфейс**
🐞 Номер телефона не выглядит кликабельным либо клик выполняет действие — *курсор меняется на pointer, клик действия не выполняет*

## 2. Управление товарами

**Позитив**
✅ Кнопка добавления товара создаёт товар в корзине в количестве 1
✅ Кнопка изменения количества товара меняет количество
✅ Кнопка «Корзина» (значок мусорки) убирает товар из корзины
🐞 Количество одного товара в корзине ограничено верхним пределом — *предел не обнаружен*
⬜ Ввод промокода даёт скидку — *не проверено: нет действующего промокода*
✅ Добавление опций (добавок) в блюдо меняет состав блюда
🐞 Пищевая ценность блюда пересчитывается при добавлении опции с пометкой kkal — *не пересчитывается пропорционально*
🐞 Пищевая ценность блюда соответствует его составу — *указана как 0/0/0, после добавления ананаса становится 0/0/30*

**Границы**
✅ Изменение количества товара с 1 до 0 убирает товар из корзины
🐞 Уменьшение количества товара с 1 до 0 в подробной карточке товара убирает его из корзины — *товар остаётся в корзине*

**Негатив**
⬜ Применение промокода при пустой корзине невозможно — *не проверено: нет действующего промокода*
✅ Добавление товара, которого нет в наличии, невозможно

**Интерфейс**
🐞 Слово «промокод» написано без опечатки — *написано «промо код»*
🐞 В режиме без картинок кнопка «Поделиться» не закрывает описание продукта — *закрывает*
